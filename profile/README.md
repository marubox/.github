## Business Box

Booking software for small businesses in Japan: booking pages, Google and Outlook calendar sync, Japanese public holidays built in, and card payment in yen straight into your own Stripe account. English and Japanese, free plan with no time limit.

**Website:** [marubox.jp](https://marubox.jp/) · **App:** [app.marubox.jp](https://app.marubox.jp/) · **LinkedIn:** [Business Box](https://www.linkedin.com/company/marubox/)

### For developers

- **[Business Box API](https://github.com/marubox/business-box-api)**: REST API for event types, open slots, bookings, invite links and webhooks. Docs at [marubox.jp/developers](https://marubox.jp/developers/), [OpenAPI 3.1](https://api.marubox.jp/v1/openapi.json), and a [Postman workspace](https://www.postman.com/marubox-2121809/business-box-api).
- **[Japanese holidays](https://github.com/marubox/japanese-holidays)**: every public holiday in Japan since 1955 as free JSON, CSV and iCalendar, with English names and substitute holidays worked out. No key, CORS enabled.
